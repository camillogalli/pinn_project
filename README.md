**Analyzing Wave Turbulence fluxes with a combined PINN/DeepONet framework**


This is a physics informed approach to Wave Turbulennce theory; where we create a neural network capable of learning fluxes, starting from the wave kinetic equation of a given physical model.

The work features two different approaches in the hope of combining the two into a more powerful network.

Features:
- Physics informed neural networks vs operator learning
- numerical computation of fluxes for different collision integrals
- transport equation case
- MMT case
- generalzation to a three waves interaction kernel.

The last two points are still to be tackled.
